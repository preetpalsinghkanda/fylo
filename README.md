# Fylo dark theme landing page

A dark theme landing page built with React and Tailwind CSS.The project focused on creating a clean, modern UI with a simple and user friendly design.

## Live URL

`https://fylo-eight-mu.vercel.app/`


## Tech Stack

- HTML
- CSS
- React js
- Tailwind CSSP
- Font Awesome Icon


## Features

- Design for Desktop
- Clean and Modern UI (Dark Theme)
- Hover states for interative elements
- Social media icons by font awesome
- Fast and lightweight


## What I Learned

While making this amazing landing page, i become more confident and polished my skills in tailwind css and react js.
i also polished how to make clean layouts, add some smooth hover effects, with modern UI.


## Inspiration

I built this landing page while practicing react and tailwind css.. i liked the simple layout and dark ui of the Fylo design, so i wanted to recreate it and also practice building the different sections with reusable react components
